## The response depends on the SDK

The server shapes the response by SDK platform and `X-ZS-SDK-Version`. The platform comes from `X-ZS-SDK-Platform` (sent by Android) or else from the User-Agent.

| Caller | Shape |
|---|---|
| iOS with ZeroSettleKit 1.6.0 or later | Full: answer options are objects with `route`, plus the `deflect` and `downgrade` blocks, and the offer carries `duration_unit`. |
| Android (every released version, 1.2.1 and earlier), including Flutter apps on Android | Legacy: answer options are plain label strings. No `deflect` or `downgrade`. A later release adds the full shape. |
| Older iOS, Flutter 1.7.0 on iOS (it bundles ZeroSettleKit 1.5.x), and direct calls | Base: answer options are objects without `route`. No `deflect` or `downgrade`. |

If you call this endpoint directly without those headers, you get the base shape.

When the cancel flow is turned off or not configured, the response is just `{"enabled": false}`.

Send the `id` values you receive back as `question_id` and `selected_option_id` in [Submit Cancel Flow Response](/api-reference/endpoint/submit-cancel-flow-response).
