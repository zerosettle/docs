## Current versions and requirements

| Platform | Package | Current version | Requirements |
| --- | --- | --- | --- |
| iOS | [ZeroSettleKit](https://github.com/zerosettle/ZeroSettleKit) (Swift Package Manager) | 1.7.0 | iOS 17.0+, Swift 6.1+, Xcode 16.3+ |
| Android | [`io.zerosettle:zerosettle-android`](https://central.sonatype.com/artifact/io.zerosettle/zerosettle-android) (Maven Central) | 1.4.0 | Android API 23+ (minSdk 23), Kotlin 2.1+ |
| Flutter | [`zerosettle`](https://pub.dev/packages/zerosettle) (pub.dev) | 1.9.0 | Flutter 3.38.9+, Dart 3.10.8+, iOS 18.0+ (CocoaPods), Android API 26+ |
| React Native (preview) | `react-native-zerosettle` (not published yet; contact support@zerosettle.io for early access) | 1.1.0 | iOS 17.0+, New Architecture. iOS only |

<Note>
  The Flutter plugin pulls in the native SDKs for you. Flutter 1.9.0 depends on ZeroSettleKit `~> 1.7.0` on iOS and `zerosettle-android` 1.4.0 on Android. The React Native 1.1.0 package pulls ZeroSettleKit from Swift Package Manager at `1.1.0` or later within the same major version, so a fresh install resolves to the latest 1.x release.
</Note>

See [Installation](/iap/installation) for the install commands and [Release notes](/releases) for what changed in each version.

## Offer view tracking

On-screen offer impression tracking (the **Viewed/Shown** stage in **Campaign → Analyze**)
requires the minimum SDK versions below. Older SDKs still convert and report purchases
correctly, but they cannot report on-screen views, so the Viewed stage under-reports and
the view-based conversion rate is unavailable.

| Platform | Minimum version | Released |
| --- | --- | --- |
| iOS (ZeroSettleKit) | 1.5.0 | 2026-06-01 |
| Android | 1.2.0 | 2026-06-01 |
| Flutter | 1.6.0 | 2026-06-01 |

Update your SDK to at least the version above to populate the Viewed stage and the
view-based conversion rate in the migration and upgrade analytics.
