title: 'Report Checked Features'
openapi: 'POST /iap/features/checked/'
---

<Warning>
  No released SDK calls this endpoint yet. The app side of plans is coming in a later SDK release.
</Warning>

A ZeroSettle SDK calls this endpoint on its own to report which feature keys your app checks. You do not call it yourself. Up to 50 keys go in one request, and each key is at most 64 characters. Authenticate with the publishable key in the `X-ZeroSettle-Key` header, as with the other SDK endpoints.

```json
{ "keys": ["custom_styles", "export_quality"] }
```

A successful call returns `204 No Content`. A body that is not a JSON object with a `keys` list of up to 50 strings of 64 characters or fewer returns `400`, and a missing or invalid key returns `401`.

## What it records

- Unknown or archived keys are ignored.
- For each known key, ZeroSettle records when it was first and last checked. Last-checked updates at most once an hour.
- The dashboard shows these keys as "Checked from your app", and a feature's key can no longer be renamed once your app checks it.
