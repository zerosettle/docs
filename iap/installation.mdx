## Swift (iOS)

Add ZeroSettleKit via Swift Package Manager in Xcode:

**Xcode UI**: File > Add Package Dependencies, then enter:

```
https://github.com/zerosettle/ZeroSettleKit
```

**Or** add it to your `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/zerosettle/ZeroSettleKit", from: "1.6.2")
]
```

Then add `ZeroSettleKit` as a dependency of your target.

<Note>
  Requires iOS 17.0+, Swift 6.1+ and Xcode 16.3+. See [SDK versions](/iap/sdk-versions) for the requirements of every platform.
</Note>

### Privacy manifest

ZeroSettleKit ships its own `PrivacyInfo.xcprivacy` (SDK 1.6.0+). You do not
need to declare the SDK's `UserDefaults` access or the data it sends in your
app's manifest — Xcode aggregates ours into your app's privacy report.

It declares `NSPrivacyTracking` as `false`, `NSPrivacyAccessedAPICategoryUserDefaults`
with reason `CA92.1`, and four collected data types: user ID, purchase history,
and — only if you pass them — customer name and email.

<Note>
  Your app still needs its own `PrivacyInfo.xcprivacy` for whatever *it* does.
  Ours covers the SDK only.
</Note>

### Dependencies and checkout mode

ZeroSettleKit declares one package dependency, [stripe-ios](https://github.com/stripe/stripe-ios). Web view checkout is the default and needs no extra setup.

<Note>
  Native Apple Pay checkout (the `NativePay` package trait) is not supported for new integrations. Use web view checkout.
</Note>

### Verify Installation

```swift
import ZeroSettleKit

// If this compiles, you're good
print(ZeroSettle.shared)
```

<Tip>
  Installing the prebuilt `ZeroSettleKit.xcframework` instead of the Swift package? Select **Embed & Sign** for it under your target's **Frameworks, Libraries, and Embedded Content**. Swift Package Manager handles embedding for you — no action needed.
</Tip>

## Kotlin (Android)

Add the ZeroSettle SDK from [Maven Central](https://central.sonatype.com/artifact/io.zerosettle/zerosettle-android):

```kotlin
// build.gradle.kts (app module)
dependencies {
    implementation("io.zerosettle:zerosettle-android:1.2.1")
}
```

**Or** using the Gradle version catalog:

```toml
# gradle/libs.versions.toml
[versions]
zerosettle = "1.2.1"

[libraries]
zerosettle = { module = "io.zerosettle:zerosettle-android", version.ref = "zerosettle" }
```

```kotlin
// build.gradle.kts (app module)
dependencies {
    implementation(libs.zerosettle)
}
```

Then sync Gradle.

<Note>
  Requires Android API 23+ and Kotlin 2.1+. See [SDK versions](/iap/sdk-versions). The SDK uses Kotlin coroutines and `kotlinx.serialization` internally.
</Note>

### Verify Installation

```kotlin
import com.zerosettle.sdk.ZeroSettle

// If this compiles, you're good
println(ZeroSettle.isConfigured.value)
```

### Resources

- [Maven Central: io.zerosettle:zerosettle-android](https://central.sonatype.com/artifact/io.zerosettle/zerosettle-android)
- [GitHub: ZeroSettle-Android](https://github.com/zerosettle/ZeroSettle-Android)

## Flutter

Add the ZeroSettle package from [pub.dev](https://pub.dev/packages/zerosettle):

```bash
flutter pub add zerosettle
```

**Or** add it to your `pubspec.yaml`:

```yaml
dependencies:
  zerosettle: ^1.7.0
```

Then run `flutter pub get`.

<Note>
  Requires Flutter 3.38.9+, Dart 3.10.8+, iOS 18.0+ and/or Android API 26+. See [SDK versions](/iap/sdk-versions). The Flutter SDK wraps the native ZeroSettleKit (iOS) and zerosettle-android (Android) SDKs — it uses CocoaPods and Maven Central to pull in the native frameworks automatically.
</Note>

### Verify Installation

```dart
import 'package:zerosettle/zerosettle.dart';

// If this compiles, you're good
final zs = ZeroSettle.instance;
```

### Resources

- [pub.dev/packages/zerosettle](https://pub.dev/packages/zerosettle)
- [GitHub: ZeroSettle-Flutter](https://github.com/zerosettle/ZeroSettle-Flutter)

## React Native (preview)

<Warning>
  React Native support is a preview. The package is **not published to npm**, and version 1.1.0 is iOS only. Install it from the public GitHub repository at the `1.1.0` tag.
</Warning>

```bash
npm install github:zerosettle/ZeroSettle-ReactNative#1.1.0
# or
yarn add github:zerosettle/ZeroSettle-ReactNative#1.1.0
```

Then run `cd ios && pod install`.

<Note>
  Requires iOS 17.0+ and the React Native New Architecture. Android is not available: the package renders an empty view there. The podspec pulls ZeroSettleKit from Swift Package Manager at `1.1.0` or later within the 1.x series, so a fresh install gets the latest 1.x release. See [SDK versions](/iap/sdk-versions).
</Note>

### Verify Installation

```typescript
import { ZeroSettleKit } from 'react-native-zerosettle';

// `ZeroSettleKit` is the singleton instance — call methods on it directly.
ZeroSettleKit.configure({ publishableKey: 'zs_pk_test_...' });
```

<Note>
  React Native 1.1.0 uses the `bootstrap(userId)` identity model. Every other platform is identify-first.
</Note>

**Resources:**
- [GitHub: ZeroSettle-ReactNative](https://github.com/zerosettle/ZeroSettle-ReactNative)

## Stripe Setup

Before integrating the SDK, connect your Stripe account on the [dashboard](https://dashboard.zerosettle.io):

| Mode | Description | Setup |
|------|-------------|-------|
| **Managed** (default) | ZeroSettle creates Stripe products for you via Express | One-click onboarding on the dashboard |
| **BYOS** (Bring Your Own Stripe) | Use your own Stripe account and existing products | Connect via OAuth, then map products in [Stripe Catalog](/iap/stripe-catalog) |

For a complete walkthrough of Stripe setup, product creation, and API keys, see [Account Setup](/iap/account-setup).

Both modes use the same SDK integration — no code differences. The mode only affects how payments are processed on the backend.
