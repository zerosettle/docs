---
title: 'Read Balances'
openapi: 'GET /usage'
---

<Warning>
  This endpoint is not released yet.
</Warning>

Returns a person's plan, add-ons and the balance in each currency, and spends nothing. Authenticate with a secret key. An unknown user gets the Free view and is not created.

Use it on your server, for example to show "318 of 500 left" in a web page. An app reads the same data with the publishable key through the SDK; see [Usage limits and credits](/iap/usage-limits).

Error: `400 user_id_required`.
