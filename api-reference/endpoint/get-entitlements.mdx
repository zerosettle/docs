---
title: 'Get Entitlements'
openapi: 'GET /iap/entitlements'
---

<Note>
  Each entitlement carries an `environment` field, `live` or `sandbox`. A request made with a live publishable key also returns the user's active sandbox StoreKit entitlements from TestFlight and App Review purchases synced with the live key, never sandbox web checkouts. A request made with a sandbox key never returns live entitlements. When both environments hold the same product, the live entitlement is returned.
</Note>
