## 1.0.0

<Update label="1.0.0">
### Ground-up rewrite — parity with ZeroSettleKit (iOS)

`1.0.0` is a complete rewrite mirroring the current iOS `ZeroSettleKit` API. The pre-1.0 `0.x` line is yanked from Maven Central; see [Migrating from v0](/sdk/android/migration-from-v0) for the symbol mapping.

- **Identify-first surface**: `ZeroSettle.configure(context, ZeroSettleConfig(...))` then `ZeroSettle.identify(Identity.User / Anonymous / Deferred)`. No `bootstrap()`, no per-`userId` method overloads — every call resolves against the identified user.
- **Two artifacts**: headless `:core` (pure Kotlin + coroutines) and optional `:ui` (Compose components).
- **Unified `OfferManager`**: a single state machine for Switch & Save migrations (Play→web, StoreKit→web) and subscription upgrades, replacing the migration-only `ZSMigrationManager`.
- **Native Play Billing origination**: `purchaseViaPlayBilling()` plus a DataStore-backed persistent `PlaySyncQueue` and a defined [acknowledgement model](/sdk/android/acknowledgement-model).
- **Switch & Save for Play**: Play→web migration via Google's External Content Link (ECL) billing program (`ZeroSettle.launchSwitchAndSave(activity)`).
- **Pending actions**: backend-initiated prompts surfaced as a typed `PendingAction` sealed class on `ZeroSettle.pendingActions`, dismissed via `dismissPendingAction()`.
- **Cross-account claims**: `ZeroSettle.transferPlayOwnershipToCurrentUser(productId)` resolves a `PendingClaim`.
- **Reactive surface**: `StateFlow` (`entitlements`, `products`, `pendingActions`, `pendingClaims`, `isUcbEnabled`, …) and a `SharedFlow<ZeroSettleEvent>` (`events`) — no delegate interface.
- **Sandbox vs live** signalled purely by the publishable-key prefix (`zs_pk_test_` / `zs_pk_live_`).
</Update>

## February 2026 (pre-1.0, yanked)

<Update label="0.15.0" description="2026-02-25">
### Subscription group support

- **Subscription groups**: Added `subscriptionGroupId` to the Product model for managing mutual exclusion between subscription tiers
</Update>

<Update label="0.14.0" description="2026-02-24">
### Transaction history & upgrade offers

- **Transaction history**: Users can now view their past transactions
- **Upgrade offers**: Support for presenting in-app upgrade offers to existing subscribers
- **API improvements**: Additional endpoint integrations for richer data
</Update>

<Update label="0.12.0 — 0.13.0" description="2026-02-22">
### API stabilization

Pre-1.0 API alignment with ZeroSettleKit 0.13.0:

- **Cancel flow**: Added headless cancel flow primitives for custom cancellation UIs
- **Migration prompts**: Configurable CTA text on `MigrationPrompt`
- **Breaking**: Namespace changes to align with iOS SDK conventions
</Update>

<Update label="0.11.0" description="2026-02-17">
### Cancel flow & namespace refactor

- **Cancel flow**: Full cancel flow implementation for managing subscription cancellations
- **Namespace refactor**: Package structure reorganized for consistency across SDKs
</Update>

<Update label="0.10.0" description="2026-02-15">
### StoreKit-only items

Added support for marking products as StoreKit-only, allowing mixed catalogs where some items use native billing and others use web checkout.
</Update>

<Update label="0.9.0" description="2026-02-13">
### Initial release

First public release of the Android SDK with full framework support:

- Product catalog fetching
- Web checkout via payment sheet
- Entitlement management
- Switch & Save migration flow
- Sandbox/Live mode via API key prefix
</Update>
